# Portfólio — Gustavo Tenório

Site pessoal com minha trajetória, habilidades e projetos.

🔗 **Ver online:** https://calm-quokka-acb075.netlify.app/

## Tecnologias
- HTML5, CSS3 e JavaScript
- Bootstrap 5, AOS, Swiper, Isotope, GLightbox, Typed.js
- Hospedagem e formulário de contato via **Netlify** (Netlify Forms)

## Estrutura
```
index.html               # página principal (sobre, habilidades, currículo, portfólio, contato)
portfolio-details.html   # detalhes de projeto
service-details.html     # detalhes de serviço
assets/                  # CSS, JS, imagens e bibliotecas
```

## Rodando localmente
Basta abrir o `index.html` no navegador, ou servir a pasta:
```bash
python -m http.server 8000
```

## Créditos
Baseado no template [iPortfolio](https://bootstrapmade.com/iportfolio-bootstrap-portfolio-websites-template/) da BootstrapMade.
